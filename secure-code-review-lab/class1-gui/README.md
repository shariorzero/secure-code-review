# Class 1 ল্যাব GUI

`index.html` একটি স্বয়ংসম্পূর্ণ পাতা, যেখানে শিক্ষার্থীরা `curl` না লিখে ফর্মে ইনপুট দিয়ে Flask ল্যাবের প্রতিটি রুট পরীক্ষা করতে পারবে (ক্যালকুলেটর, কোড রানার, লগইন ও কুকি, অ্যাডমিন রিপোর্ট, ত্রুটি পাতা, CORS)। প্রতিটি কার্ডে ফলাফলের সাথে কোন `# RED FLAG`-এর সাথে সম্পর্ক ও কী প্রশ্ন করতে হবে তা লেখা আছে।

## কেন অনলাইনে হোস্ট করা পাতা নয়
এই GUI সরাসরি `http://localhost:5000`-এ চলা Flask অ্যাপকে কল করে। তাই এটি **ছাত্রের নিজের ব্রাউজারে স্থানীয়ভাবে খোলা** লাগবে, যেখানে Flask অ্যাপও চলছে। একটি সাধারণ ওয়েবসাইট হিসেবে কোথাও হোস্ট করলে এটি `localhost`-এ পৌঁছাতে পারবে না।

## চালানোর ধাপ (Codespaces)

**টার্মিনাল ১ — Flask অ্যাপ:**
```bash
python student/app.py            # অথবা vulnerable/app.py, fixed/app.py
```

**টার্মিনাল ২ — GUI সার্ভ করা:**
```bash
python -m http.server 8080 --directory class1-gui
```

এবার **PORTS** ট্যাব থেকে `8080` খুলুন, GUI পাতা আসবে। ওপরের বাক্সে সার্ভারের ঠিকানা (ডিফল্টে `http://localhost:5000`) ঠিক আছে কিনা দেখে **সংযোগ পরীক্ষা** চাপুন।

GUI আর Flask অ্যাপ দুটো আলাদা পোর্টে (৮০৮০ ও ৫০০০) চলছে বলেই CORS কার্ডটি আসল পরীক্ষা করে, কোনো ভান করা লাগে না।

## `fixed/app.py`-এর বিপরীতে চালালে
`fixed/app.py` শুধু `ALLOWED_ORIGINS`-এ লেখা origin-কে অনুমতি দেয় (ডিফল্টে `http://localhost:3000`)। GUI পোর্ট ৮০৮০-কে অনুমতি দিতে:
```bash
export ALLOWED_ORIGINS="http://localhost:3000,http://localhost:8080"
python fixed/app.py
```
না বদলালে CORS কার্ডে অনুরোধ আটকে যাবে, এটাও একটা বৈধ শিক্ষণীয় ফলাফল: ফিক্স কাজ করছে প্রমাণ হলো।

## লগইন কুকি পরীক্ষা
`vulnerable`/`student` অ্যাপে লগইনের পর "জাভাস্ক্রিপ্ট দিয়ে কুকি পড়ো" চাপলে কুকির মান দেখা যাবে (HttpOnly বন্ধ)। `fixed` অ্যাপে (HttpOnly চালু থাকলে) ফলাফল খালি আসবে।
